# Permissions

**Server permission nodes for Reden-Reforged.**  
Set them with any permissions mod, like LuckPerms.

## Nodes

- `reden.undo.creative` - undo/redo in creative 
- `reden.undo.survival` - undo/redo in survival 
- `reden.undo.kill.others` - undo a `/kill` of another 

## Survival undo

Players also need to turn off **creativeOnly** in the settings (press R+C in game).

## Example

```bash
/lp group default permission set reden.undo.survival true
```
